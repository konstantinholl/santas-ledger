# Reflecting on the building of the first website

## Experiences

Quite frankly, this was not the first website I built using AI to assist me. Exspecially throughout the last couple of weeks I built a couple of little websites, so I already had made some experiences that I could use to my advantage.
This lecture taught me to not take the results as a given, but to stay in control of them plus that through refining your prompts you can get better results.

In order to build my Santa Ledger I therefor first told an AI what I wanted to do, what it should look like and what I need to hand in, and then told it to formulate a nice promt I could give to my Github Copilot agent.
With earlier project I had quite some work to do afterwards.. this time not as much.
To be honest, I implemented the website twice, but the first iteration was super complex and I didn't like the colors, so I refined my original prompt and ran it again. The second itereation was much better and I was happy with the result.

Since it was a quite simple website, I was satified enough to call it a day. I found a couple of things that need some improvement, but as the goal was a static website and I already overshot that goal, I decided to stop.

## Time saving

One thing I changed however was the dataset. The dataset of a studetn didn't really match the theme of the Santa Ledger, so I let AI create another dataset. But when I ran the website it was still the old dataset showing up. So what I did was ofcourse tell the agent to change it. Looking back I should have just changed it myself, because the change was litteraly just changing the name of the file in the code.. I could have saved electricity as well as time by doing it myself.

## Making the website my own

We only briefly touched on the topic that AI can will make most websites look alike. How I would fic this is to really give clear instructions on what I want it to look like beforehand, so that the initial website already rerpesents my style of website and not the biased style of all websites already out there.
